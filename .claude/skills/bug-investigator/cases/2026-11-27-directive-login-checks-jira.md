Rule:      Post one login-checks comment a day at about 20:45 on the week's [Sanity checks] ticket, in the order comment's layout ("<M/D> Login checks = PASS|FAILED (<n> runs: sites)", bullets, the day's login Excel, a sites-by-slot grid). Read the live login-health-only output only; never change the live monitor for this. When 3 or more sites fail together in one cycle on network or timeout errors and pass in the next cycle, call it "slow connection on the PC" and keep the day PASS. A site failing alone, any non-network error, or the same site failing 2 or more cycles in a row is a real FAILED. The Friday hand-over (Ready for review, assign the lead) happens only in this step, and only if every order site and a complete, unfailed login day passed. A missed Friday is handed over by the next batch or login step. Demo on the next ticket (DIG-759) with no cc. Turn the cc on only when the owner says it is live. Leave this week's ticket alone.
